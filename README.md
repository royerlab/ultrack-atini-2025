# Ultrack Advanced Techniques in Neuroimaging Workshop

This repository contains the materials for the Ultrack workshop at ATiNI 2025.

Clone this repository to your local machine to folow the tutorial by running:

```bash
git clone https://github.com/royerlab/ultrack-atini-2025
```

You can refer the [workshop website](https://royerlab.github.io/ultrack-atini-2025/) for more information.

## Installation

This is also available in the website in [this section](https://royerlab.github.io/ultrack-atini-2025/installation.html).
